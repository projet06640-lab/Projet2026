## ⚙️ Workflow complet de production

```

ÉTAPE 5 — EXPORT + PUBLICATION
9:16 vertical, 1080p, 30 fps
TikTok + Insta + Facebook
```

## 💰 Stratégie d'économie de crédits

**Règle d'or :** ne génère pas une vidéo entière, génère des **briques réutilisables**.

```
🎨 BRIQUES À CRÉER UNE FOIS POUR TOUTES

POUR ASTRO FUN
- 12 mascottes des signes (1 par signe, animées 4s en loop)
- 5 fonds cosmiques différents (loops 5s)
- 1 intro de marque (3s)
- 1 outro CTA (3s)
TOTAL : ~20 clips de base = 1 mois de production

POUR FRICOM
- 3 B-rolls lifestyle (matin, après-midi, soir)
- 2 ambiances "déballage" (mains qui prennent un produit)
- 1 intro (problème)
- 1 outro (CTA "lien en bio")
TOTAL : ~7 clips de base = réutilisable sur 20 pubs
```

**Avec ces briques**, chaque nouvelle vidéo se monte en 5-10 min sans nouvelle génération IA, juste de l'assemblage CapCut. **Tu économises 90% de tes crédits.**

## 🚫 Erreurs à éviter

```
❌ Générer du texte dans la vidéo IA
→ Les outils IA hallucinent les textes. Ajoute toujours le texte dans CapCut, pas dans le prompt.

❌ Prompts trop longs (>80 mots)
→ Au-delà, les outils IA décrochent. Concis et précis vaut mieux que détaillé.

❌ Vouloir 10 secondes d'un coup
→ Les outils sont meilleurs sur 4-6 secondes. Pour 30s, assemble 5 clips dans CapCut.

❌ Changer d'outil à chaque vidéo
→ Reste sur 1 ou 2 outils que tu maîtrises. Cohérence visuelle = signature de marque.

❌ Payer plusieurs abonnements pro en même temps
→ Au démarrage, 1 seul outil payant (Kling à 30€/mois) suffit largement.
```

## Règles de production

- **Pas de jargon non expliqué** : si terme technique (LoRA, denoising, etc.), 1 ligne d'explication
- **Toujours préciser le format** : 9:16 vertical pour TikTok/Reels/FB
- **Toujours rappeler le coût** : Marc doit savoir combien il dépense avant de générer
- **Pédagogie sur les limites** : si l'outil va décrocher (texte, mains, foule), prévenir
- **Réutilisation maximale** : toujours suggérer comment réutiliser le clip généré
