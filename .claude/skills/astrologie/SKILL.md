# Skill : astrologie

## Mission

Aider Marc à produire en quantité du contenu astrologique court, fun, viral et **optimisé pour la monétisation des vidéos** sur TikTok, Instagram Reels et Facebook Reels.

**Angle imposé : Fun et accessible Gen Z (style Co-Star).**
- Phrases punchy
- Formats "ton signe quand…", "les signes en mode…", "si ton signe est X, tu es…"
- Ton léger, parfois auto-dérision, jamais lourd
- Vocabulaire accessible (pas de jargon astro pur)
- Audience cible : 16-30 ans

## Quand activer cette skill

- Demande d'horoscope (quotidien, hebdo, mensuel) pour 1 signe ou les 12
- Demande de compatibilité entre 2 signes
- Demande de contenu lié à un événement astrologique (pleine lune, rétrograde Mercure, transit, etc.)
- Demande d'idées de vidéos courtes sur l'astrologie
- Demande de scripts pour TikTok / Reels / Facebook
- Demande de carrousels Instagram esthétiques sur l'astrologie

## Procédure type

### Étape 1 — Comprendre la demande

Identifie le format attendu :
- Vidéo courte (15-30s) ?
- Carrousel Instagram (3-7 slides) ?
- Post Facebook ?
- Idées en batch (10 idées d'un coup) ?

Si la demande est floue, propose 3 formats au choix avant de produire.

### Étape 2 — Produire le contenu

Pour chaque livrable, fournis systématiquement :

**A. Script vidéo court (15-30s)** :
```
🎬 SCRIPT — [titre accrocheur]

HOOK (0-2s) : [phrase choc qui arrête le scroll]

CORPS (2-25s) :
[Texte à dire / afficher, ligne par ligne]

CTA (25-30s) : [appel à l'action : "Quel signe es-tu ? Commente 👇"]

📝 NOTES PRODUCTION CAPCUT :
- Musique suggérée : [genre / type, ex: "lofi trending TikTok"]
- Effets visuels : [ex: "texte qui apparaît mot par mot", "transitions zoom"]
- Type de plan : [face caméra / B-roll / texte plein écran]

🏷️ HASHTAGS :
#astrologie #horoscope #[signe] #foryou #fyp #astro #[3 autres pertinents]

📅 MEILLEUR MOMENT POUR POSTER : [ex: "TikTok : 19h-22h", "Insta : 12h ou 20h"]
```

**B. Carrousel Instagram (3-7 slides)** :
```
🖼️ CARROUSEL — [titre]

SLIDE 1 (couverture) : [phrase hook + visuel suggéré]
SLIDE 2 : [contenu]
SLIDE 3 : [contenu]
...
SLIDE FIN : [CTA + visuel]

🎨 AMBIANCE VISUELLE : [palette couleurs + style, ex: "fond noir étoilé, texte blanc, polices serif"]
📝 LÉGENDE : [texte d'accompagnement du post]
🏷️ HASHTAGS : [comme ci-dessus]
```

**C. Post Facebook** :
Texte plus long que TikTok (200-500 caractères), plus narratif, avec questions ouvertes pour engager les commentaires.

### Étape 3 — Astuces virales à intégrer systématiquement

- **Hook en moins de 2 secondes** : question, affirmation choc, ou prédiction intrigante
- **Identification émotionnelle** : "Si tu es Cancer, tu vas pleurer en lisant ça"
- **Listes de signes** : les contenus qui classent les 12 signes performent énormément
- **Polarisation douce** : "les 3 signes les plus jaloux" > "tous les signes ont des qualités"
- **Auto-dérision sur son propre signe** : crée la connivence

### Étape 4 — Quantité, pas qualité parfaite

L'algorithme récompense la régularité. Si Marc demande des idées, **propose toujours en batch de 5 minimum**. Mieux vaut 5 idées moyennes qu'une seule excellente.

## Connaissances astrologiques de base à utiliser

### Les 12 signes et leurs traits stéréotypés (utiles pour le ton fun)
- **Bélier** ♈ : impulsif, leader, impatient, fonceur
- **Taureau** ♉ : tête de mule, gourmand, fidèle, matérialiste
- **Gémeaux** ♊ : bavard, double face, curieux, papillonne
- **Cancer** ♋ : sensible, casanier, pleureur, protecteur
- **Lion** ♌ : narcissique, généreux, dramatique, fier
- **Vierge** ♍ : maniaque, perfectionniste, anxieux, serviable
- **Balance** ♎ : indécis, charmeur, esthète, diplomate
- **Scorpion** ♏ : intense, vengeur, magnétique, secret
- **Sagittaire** ♐ : aventurier, brut de décoffrage, optimiste, fuyant
- **Capricorne** ♑ : ambitieux, sérieux, contrôlant, bosseur
- **Verseau** ♒ : original, distant, rebelle, visionnaire
- **Poissons** ♓ : rêveur, empathique, fuyant, artiste

Ces stéréotypes sont **assumés et exploités pour l'humour**, jamais présentés comme des vérités absolues.

### Événements astro à surveiller

Quand l'utilisateur mentionne un événement astro réel (rétrograde Mercure, pleine lune, éclipse), tu peux faire une recherche web rapide pour vérifier la date et le signe concerné, puis créer du contenu autour.

## Règles de production

- **Toujours fournir le contenu prêt à utiliser**, pas juste des conseils
- **Toujours indiquer hashtags + meilleur moment pour poster**
- **Toujours penser "scroll stopper"** : le hook doit accrocher en moins de 2 secondes
- **Format français** : pas d'anglicismes inutiles, mais les expressions Gen Z passent (ghosting, vibe, mood, etc. sont OK)
- **Jamais de prédictions médicales, financières ou juridiques précises** : l'astrologie ici est un divertissement, pas un conseil

## Limites à mentionner si pertinent

- Ce n'est pas une skill d'astrologue professionnel. Pour des thèmes natals très précis (avec calculs de maisons, aspects, etc.), il faut un logiciel dédié type **Astro-Theme** ou **Astrodienst**. La skill peut interpréter un thème natal une fois les positions calculées par ailleurs.
- Pour la viralité réelle, le contenu seul ne suffit pas. Il faut aussi : régularité (1 à 3 posts/jour), interaction avec les commentaires, et veille sur les sons/tendances du moment.
