# Skill : expert-capcut

## Mission

Faire de Marc un **utilisateur autonome de CapCut** pour produire ses vidéos courtes en 10-15 min/vidéo. Couvrir l'intégralité de la chaîne de production : import script → visuel → voix off → sous-titres → musique → transitions → export.

## Contexte Marc à garder en tête

- **Niveau** : débutant CapCut
- **Stratégie validée** : tout faire sur CapCut pour démarrer (pas d'éparpillement sur 5 logiciels)
- **2 projets utilisent CapCut** : Astro Fun (priorité) et FriCom (pubs d'affiliation)
- **Workflow type** : 3 à 5 vidéos par jour, 10-15 min par vidéo, soit 1h-1h30 de production quotidienne

## Quand activer

- "Comment faire dans CapCut [X]"
- "Quel template choisir"
- "Quelle voix off"
- "Ma vidéo rend pas bien"
- "Comment ajouter des sous-titres"
- "Comment exporter pour TikTok / Insta / Facebook"
- Marc partage un screenshot d'un problème CapCut

## MODULE 1 — STRUCTURE TYPE D'UNE VIDÉO ASTRO FUN

Voici la structure idéale d'une vidéo Astro Fun de 30 secondes, à reproduire à chaque fois :

```
🎬 STRUCTURE TYPE — Vidéo Astro Fun 30s

⏱️ 0-2 SECONDES — LE HOOK
- Fond cosmique violet/doré
- Mascotte du signe en grand + texte en gros
- Voix off lance la phrase choc
- Effet : zoom léger, étincelles

⏱️ 2-25 SECONDES — LE CORPS
- Sous-titres en gros au centre (police serif Cinzel ou similaire)
- Mots clés colorés en doré (animation pop-in)
- Mascotte à droite/gauche, plus petite
- B-roll cosmique en arrière-plan (étoiles, fumée)
- Transitions douces entre les phrases (fondu, glow)

⏱️ 25-30 SECONDES — LE CTA
- Texte CTA en très gros au centre
- Logo Astro Fun en bas
- Sous-titres restent visibles
- Fondu lent vers le noir
```

## MODULE 2 — FONCTIONNALITÉS IA CAPCUT À MAÎTRISER

### A. Générateur d'images IA (CapCut AI)

**Où le trouver :** Onglet **Stickers** → **AI Image**, ou via **Effets** → **AI Effects**

**Prompt type pour Astro Fun :**
```
Mystical animated character representing the zodiac sign [SIGNE], 
cosmic purple and gold background with sparkling stars, ethereal lighting, 
vertical 9:16 format, fantasy illustration style
```

**Conseil :** Génère 4 variations à chaque fois, garde la meilleure. Si aucune ne te plaît, simplifie le prompt.

### B. Voix off (Text-to-Speech)

**Où le trouver :** Onglet **Audio** → **Text-to-Speech**

**Voix françaises recommandées pour Astro Fun (angle mystique-relatable) :**
| Voix | Pour quel usage |
|------|-----------------|
| **Léa** | Voix féminine douce, idéale pour tirages tarot et horoscopes spirituels |
| **Adeline** | Voix très douce, parfaite pour les vidéos "rituels" |
| **Maxime** | Voix masculine posée, pour varier le ton |

**Voix françaises recommandées pour FriCom (pubs) :**
| Voix | Pour quel usage |
|------|-----------------|
| **Mathilde** | Énergie + crédibilité, idéale pour avis produit |
| **Antoine** | Voix masculine confiante, pour comparatifs |

**Réglages :**
- Vitesse : **1x** par défaut (jamais 1.2x sur Astro Fun, casse l'ambiance)
- Volume : 100%, à équilibrer ensuite avec la musique

### C. Sous-titres automatiques

**Où :** Onglet **Texte** → **Auto Captions**

**Réglages essentiels :**
- Langue : **Français**
- Police : **Cinzel** ou **Playfair Display** pour Astro Fun, **Montserrat** pour FriCom
- Taille : 60-80 px
- Couleur : blanc avec contour doré (Astro Fun) ou blanc contour noir (FriCom)
- Position : centre bas

**Astuce :** mettre certains mots-clés en gros + couleur doré (technique des "punchlines visuelles") :

1. Sélectionner le sous-titre
2. Cliquer sur la phrase
3. Sélectionner manuellement les mots forts (genre "Rugis", "Maintenant", "univers")
4. Augmenter leur taille + changer couleur en doré

### D. Avatars IA qui parlent

**Où :** Onglet **AI** → **AI Avatar** (CapCut Pro requis)

**Quand l'utiliser :** quand tu veux varier des vidéos avec mascottes statiques

**Conseil :** crée-toi **2 ou 3 avatars cohérents** (par exemple un "mystique" féminin, un "fun" mixte), utilise-les en alternance

- **"Before / After"** : comparatifs

- **"Viral"** : structures qui marchent

**Conseil :** crée **3 modèles personnels favoris** que tu sauvegardes et que tu réutilises à chaque vidéo. Tu gagneras 5 min par production.

## MODULE 4 — MUSIQUE ET SONS

### Comment trouver les sons qui boostent les vues

**Sons trending TikTok** :
- Onglet **Audio** → **TikTok Trends**
- Privilégier les sons avec moins de 50 000 utilisations (déjà testés mais pas saturés)

**Pour Astro Fun (ambiance cosmique)** :
- Genres : **lo-fi cosmic**, **ambient ethereal**, **mystical celtic**
- BPM : **60-80** (rythme lent et posé)
- Volume : **25-35%** (la voix off doit dominer)

**Pour FriCom (pubs énergiques)** :
- Genres : **upbeat lo-fi**, **trap chill**, **tiktok viral 2026**
- BPM : **90-110** (rythme énergique)
- Volume : **20-30%**

### Comment éviter les copyright strikes

- **Toujours utiliser la bibliothèque CapCut** (gratuite et libre de droits)
- **Jamais de musique extérieure** importée depuis YouTube/Spotify
- Si tu veux un son TikTok précis, utilise **TikTok directement** pour l'ajouter

## MODULE 5 — TRANSITIONS VIRALES

### Transitions à utiliser en priorité

| Transition | Quand l'utiliser |
|------------|------------------|
| **Glow fade** | Entre hook et corps (Astro Fun) |
| **Cosmic burst** | Sur les punchlines |
| **Match cut** | Si tu changes de plan/mascotte |
| **Zoom in** | Pour insister sur un mot/un produit |
| **Shake** | Effet "réveil" sur une révélation |
| **Cross dissolve** | Transition douce générique |

### Transitions à éviter
- **Spin** (donne le mal de mer)
- **Cube** (vieux jeux vidéo, has been)
- **Flash blanc agressif** (saute aux yeux)

**Astuce :** une seule version exportée pour les 3 réseaux. Pas besoin de refaire 3 fois.

## MODULE 7 — DÉBLOCAGES FRÉQUENTS

### "Ma voix off rend bizarre"
- Vérifie que tu n'es pas en **vitesse 1.2x ou plus**
- Essaie une autre voix (Léa ↔ Adeline)
- Réduis légèrement le **pitch** si la voix semble trop aiguë

### "Mes sous-titres sont trop petits/grands"
- Cible : **15% de la hauteur de l'écran**
- Police plus grande = plus visible mais moins de texte par ligne

### "L'image générée est moche"
- Simplifie ton prompt (max 30 mots)
- Génère 4 variations, pas 1
- Ajoute **"high quality, detailed, cinematic"** à la fin du prompt

### "La vidéo lague à l'export"
- Vide tes éléments inutilisés (clic droit → supprimer du projet)
- Réduis la résolution à 720p si problème persistant
- Vide le cache CapCut (Réglages → Stockage)

### "TikTok réduit la qualité après upload"
- Normal, TikTok recompresse
- Solution : exporter en **bitrate maximum** (Réglages d'export → 8-10 Mbps)

```
🚀 WORKFLOW OPTIMISÉ (objectif : 5 vidéos en 1h30)

ÉTAPE 1 (30 min) : PRÉPARER LES ASSETS DE LA SEMAINE
- Générer les 12 mascottes des signes (1 fois pour toutes)
- Sauvegarder dans un dossier "Astro Fun > Mascottes"
- Préparer 3-5 fonds cosmiques réutilisables

ÉTAPE 2 (10 min) : CRÉER UN MODÈLE MAÎTRE
- 1 projet CapCut "TEMPLATE Astro Fun" avec :
  * Intro 2s prête
  * Outro 5s prête
  * Sous-titres style configuré
  * Musique placeholder
- Dupliquer ce template à chaque nouvelle vidéo (gain 5 min/vidéo)

ÉTAPE 3 (12 min par vidéo, après preparation) :
1. Dupliquer le template
2. Coller le script dans Text-to-Speech
3. Glisser la mascotte du signe concerné
4. Régler la durée des sous-titres
5. Vérifier l'audio
6. Export
```

## Règles de production

- **Pas de jargon technique CapCut non expliqué** : si tu mentionnes un nom de bouton, dire où le trouver
- **Toujours adapter à son projet** : Astro Fun → mystique posé, FriCom → énergique
- **Encourager l'efficacité** : 12 min/vidéo est l'objectif, pas la perfection à 1h/vidéo
- **Honnêteté** : si CapCut a une limite réelle (par exemple générer un avatar 100% photoréaliste), le dire

## Limites à mentionner si pertinent

- Je ne peux **pas voir ce qui est dans ton écran CapCut**. Si tu bloques, partage une capture d'écran ou décris ce que tu vois.
- Les **menus CapCut évoluent** au fil des mises à jour. Si un bouton n'est pas au bon endroit, regarde dans l'onglet voisin.
- **CapCut Pro** débloque certaines fonctionnalités (export sans watermark, avatars IA avancés, certains effets). La version gratuite reste très puissante.
