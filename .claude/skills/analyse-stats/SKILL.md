# Skill : analyse-stats

## Mission

Transformer les statistiques brutes de Marc (vues, clics, abonnés, ventes) en **3 actions concrètes** à appliquer la semaine suivante. Pas d'analyse abstraite, pas de blabla.

## Quand activer

- Marc partage des chiffres de TikTok / Instagram / Facebook / programme d'affiliation
- Marc demande pourquoi une vidéo a marché ou plante
- Marc demande comment ajuster sa stratégie

## Procédure

### 1. Demander les bons chiffres

Si Marc ne les donne pas spontanément, demande :

**Pour TikTok/Instagram/Facebook :**
- Période analysée (ex: 7 derniers jours)
- Nombre de vidéos publiées
- Vues totales et vues moyennes par vidéo
- Taux d'engagement moyen (likes + commentaires + partages / vues)
- Nouvelle abonnés sur la période
- Top 3 vidéos (titres + vues)
- Flop 3 vidéos (titres + vues)

**Pour l'affiliation (FriCom) :**
- Nombre de clics sur le lien bio
- Nombre de ventes générées
- Commission cumulée
- Produits qui ont converti

### 2. Diagnostic en 3 axes

```
📊 DIAGNOSTIC — Semaine du [date]

🎯 AXE 1 — VISIBILITÉ (vues)
[Constat : tes vues moyennes sont X, vs Y la semaine d'avant]
[Verdict : 🟢 progression / 🟡 stable / 🔴 baisse]
[Cause probable : hook trop faible / format saturé / mauvais créneau / autre]

💎 AXE 2 — ENGAGEMENT (interactions)
[Constat : ton taux d'engagement est X%]
[Verdict : 🟢 ≥10% / 🟡 5-10% / 🔴 <5%]
[Cause probable : CTA absent / contenu pas relatable / appel à commenter pas naturel]

💰 AXE 3 — CONVERSION (FriCom uniquement)
[Constat : X clics, Y ventes, Z€ générés]
[CTR sur la bio : X% (cible >2%)]
[Taux de conversion : X% (cible >1%)]
[Cause probable : produit mal aligné / bio peu claire / pas assez d'autorité]
```

### 3. 3 ACTIONS CONCRÈTES pour la semaine suivante

```
🎯 3 ACTIONS À TESTER LA SEMAINE PROCHAINE

ACTION 1 (priorité ⭐⭐⭐) : [action précise, exécutable en 30 min]
→ Hypothèse : [ce qu'on cherche à valider]
→ Indicateur de succès : [chiffre cible]

ACTION 2 (priorité ⭐⭐) : [action]
→ Hypothèse : [...]
→ Indicateur : [...]

ACTION 3 (priorité ⭐) : [action]
→ Hypothèse : [...]
→ Indicateur : [...]
```

### 4. Inscrire dans HISTORY.md

À la fin de chaque analyse, **proposer** à Marc d'ajouter une entrée datée dans `context/HISTORY.md` avec le diagnostic + actions, pour pouvoir comparer aux semaines suivantes.

## Repères de référence (à utiliser sans les imposer)

### TikTok débutant (0-1000 abonnés)
- Vues moyennes attendues : 100-1000 par vidéo
- Taux d'engagement sain : 5-10%
- Si vues <500 après 10 vidéos : problème de hook ou de niche

### Instagram Reels débutant
- Vues moyennes : 200-2000 par Reel
- Taux d'engagement : 3-8%

### Facebook Reels débutant
- Vues plus erratiques, dépend beaucoup du jour
- Taux d'engagement : 1-5%

### Affiliation
- CTR sur la bio sain : 2-5%
- Taux de conversion réaliste : 0.5-2%
- ROI positif si commission > coût pub (mais en organique, presque toujours positif)

## Règles de production

- **Pas de diagnostic vague** : toujours pointer une cause précise et une action précise
- **Pas de dramatisation** : si une semaine est mauvaise, l'expliquer et proposer une correction, pas paniquer
- **Quantifier les actions** : "augmenter le CTR" ne veut rien dire, "tester 3 hooks alternatifs sur les 5 prochaines vidéos" est actionnable
- **Honnêteté** : si les chiffres montrent qu'une stratégie ne marche pas, le dire franchement et proposer un pivot
