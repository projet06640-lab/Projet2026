# /contenu-jour

Génère le **pack quotidien complet** de contenus pour le projet Astro Fun de Marc. Objectif : qu'en une seule commande, Marc ait tous les scripts dont il a besoin pour sa journée de production CapCut.

## Étapes à exécuter

### 1. Charger le contexte
Lis (ou rappelle-toi) la skill `astro-tarot` pour appliquer le bon angle : **hybride mystique-relatable** (70% cosmique sérieux + 30% punchy accessible).

### 2. Vérifier l'événement astro du jour
Note la date du jour. Si tu connais un événement astrologique significatif en cours (pleine lune, nouvelle lune, rétrograde de Mercure, transit important, signe du Soleil actuel), utilise-le comme **fil rouge** des contenus du jour. Sinon, propose un fil rouge cohérent par toi-même (par exemple "énergie du milieu de semaine", "transition lunaire").

### 3. Produire le pack complet

#### Bloc A — Les 12 horoscopes du jour

Pour **chacun des 12 signes**, génère un script vidéo complet selon le format de la skill `astro-tarot` :

```
🎬 [SIGNE] — [titre punchy]

🎯 HOOK (0-2s) : [phrase qui arrête le scroll]

🌙 CORPS (2-25s) : [4 à 6 lignes, ton hybride mystique-relatable]

✨ CTA (25-30s) : [appel à l'action engageant]

🎨 PROMPT VISUEL CAPCUT AI : [description courte pour générer le visuel principal]

🎙️ VOIX OFF CAPCUT : [voix française recommandée, ex: "Maxime" pour masculin, "Léa" pour féminin]

🎵 AMBIANCE MUSICALE : [genre + BPM]

🏷️ HASHTAGS : [#signe + 8 autres pertinents]

📅 CRÉNEAU : [meilleure heure de publication par réseau]
```

**Ordre des signes** : Bélier → Taureau → Gémeaux → Cancer → Lion → Vierge → Balance → Scorpion → Sagittaire → Capricorne → Verseau → Poissons.

**Règle de variation** : ne reprends jamais la même structure de phrase deux fois. Chaque signe a son ton (Lion plus dramatique, Vierge plus précis, Sagittaire plus aventurier, etc.).

#### Bloc B — Le tirage de tarot du jour

Tire **1 carte des Arcanes Majeurs** (varier d'un jour à l'autre, ne pas toujours tirer La Lune ou Les Amoureux). Produis :

```
🔮 TIRAGE DU JOUR — [thème : énergie / amour / travail / message universel]

CARTE TIRÉE : [nom de la carte]

🎬 SCRIPT VIDÉO COMPLET (avec tous les éléments du format ci-dessus)

📝 INTERPRÉTATION COURTE (3-4 lignes, ton mystique-relatable)

💡 CONSEIL DU JOUR : [1 phrase actionnable]

🎨 PROMPT VISUEL pour générer la carte stylisée
```

#### Bloc C — Le bonus astro du jour

Un format court basé sur l'événement astro du jour (ou sur un thème complémentaire). Exemples :
- "Les 3 signes qui vont mal vivre la rétrograde de Mercure"
- "Pleine lune ce soir : ce que tu dois lâcher avant minuit"
- "Le signe le plus chanceux d'aujourd'hui (et pourquoi)"
- "Compatibilité du jour : [signe X] et [signe Y]"

Format complet (script + visuel + voix + musique + hashtags + créneau).

### 4. Récap final pour Marc

Termine la sortie par un récap clair :

```
✅ PACK DU JOUR PRÊT — [date]

📦 Contenu généré :
- 12 horoscopes (1 par signe)
- 1 tirage de tarot du jour
- 1 bonus astro

🎯 Fil rouge du jour : [thème astro du jour]

⏱️ Temps de production estimé sur CapCut : 1h30 à 2h pour les 14 vidéos

📅 Plan de publication suggéré :
- Matin (12h-13h) : [3 contenus à publier]
- Soir (19h-22h) : [le reste]

👉 Tu veux que je te génère :
- Les prompts détaillés pour les 12 mascottes (si pas encore créées) ?
- Des variantes pour multi-publier sur 3 réseaux sans algorithme qui détecte du copier-coller ?
- Un script bonus si tu as une idée précise ?
```

## Règles d'exécution

- **Réponse en un seul message** (pas de découpage en plusieurs réponses). Marc doit pouvoir tout copier d'un coup.
- **Ton hybride respecté à 100%** : 70% mystique / 30% relatable. Pas de dérive 100% sérieux ou 100% mèmes.
- **Pas de jargon astro pointu** sans le traduire en mots simples.
- **Quantité avant perfection** : mieux vaut 14 scripts un peu génériques que 3 chefs-d'œuvre. Marc filtrera à la production.
- **Cohérence du fil rouge** : tous les contenus du jour doivent avoir un lien avec l'événement/thème astro du jour. Ça crée une "série" cohérente sur ses réseaux.
- **Sources d'événements astro** : si la date est aujourd'hui ou très proche, et qu'un événement astro précis est en jeu, vérifier rapidement avec WebSearch pour ne pas se tromper de date ou de signe.
