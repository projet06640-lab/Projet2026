# Module : jarvis-install

Module d'installation interactif du Jarvis Starter Kit.

## Usage

Depuis la racine du workspace, lancez :

```
/install module-installs/jarvis-install
```

Claude vous interviewera pour remplir `context/CONTEXT.md` et personnaliser `CLAUDE.md` (section "Who I Am").

## Ce que fait l'installation

1. Pose une série de questions sur vous, votre activité, vos projets et vos objectifs.
2. Remplit `context/CONTEXT.md` avec vos réponses.
3. Remplit la section "Who I Am" de `CLAUDE.md`.
4. Ajoute une entrée d'installation dans `context/HISTORY.md`.
5. Vous confirme que votre Jarvis est opérationnel.

Voir `INSTALL.md` pour le détail de la procédure suivie par Claude.
